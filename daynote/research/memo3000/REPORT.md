데이터: `daynote_korean_memo_dataset_3000_diverse.csv` — 직무 16종 × 의도 21종 × 문체 4종(정돈체·대충 줄임말·빈 줄 많은 여러 줄·불릿 조각).
방법: 앱이 실제로 쓰는 길 그대로 — 짧은 명령은 AI 없이(`matchLocal`), 나머지는 `services/ai.organize`(Gemini 3.5 Flash-Lite, 프롬프트 capture.v15) → 검증 → 명령 확인 → 적용. 결과는 **앱에 최종으로 남은 상태**(만든 할 일·일정·바뀐 마감·명령)로 채점했다.

## 찾아서 고친 문제 (앱 쪽)

| 문제 | 영향(전 → 후) | 고친 내용 |
|---|---|---|
| 날짜 말 모름: 명일·금일·익일·내일모레·글피·금욜·월욜·담주·다다음 주 | 마감 다름 수백 건 | 날짜 해석기에 추가 ("내일모레"를 "내일"로 읽던 것도) |
| 시각만 있는 마감("16:30까지")을 확인 필요로 막음 | 끝 시각 할 일 31 → 142/143 | 날짜 말이 없으면 오늘(이미 지난 시각이면 내일) |
| AI가 근거에 줄 번호 "1\| "를 붙이거나 따옴표를 빼고 옮김 | 삭제 명령 121 → 143 | 근거 비교에서 줄 번호·따옴표 무시 |

| "하루만 뒤로 빼줘" 같은 동사 모름 | 97 → 143 | 빼·밀어·옮겨·넘겨·연기 추가 |

| AI가 날짜 칸에 날짜 말을 빼고 옮김("1시 반까지") | 할 일 생성 막힘 | 근거 문장의 날짜와 같으면 받음 |

## 2차 개선 (0.1.15)

| 개선 | 내용 |
|---|---|
| 정책 1 | 밤에 "15:00까지" → **내일** 15:00 (확정) |
| 정책 2 | 마감 없던 할 일 "하루 미뤄줘" → 오늘 기준 내일로 넣고, 채팅에 **[내일] [모레] [글피] [다음 주 월]** 버튼 (지금 고른 날 눌림, Ctrl+Z 되돌리기) |
| "주간 일정표 열어줘" | 캘린더 **주간 보기**로 연다 (9건 해결) |
| "…사용 가능." 같은 사실 기록 | 바로 만들지 않고 결과 카드에 제안 + **[넣기]** |
| 메모로만 남은 할 일 같은 글 | 날짜·시각 + 행동 말이 있으면 카드에 **[할 일로 만들기]** (글의 날짜를 할 날/마감으로) |
| 엉뚱한 기존 할 일 연결 | 글에 그 할 일 이름의 낱말이 하나도 없고 다른 내용이 있으면 고치지 않음 |
| AI 이름 오타 | 글자 거리 20% 이하인 할 일 하나로 맞춤 |
| 회귀 검사 | `test/memo3000.test.js` — 저장한 AI 답 3,000건을 `npm test` 마다 채점 (0.5초, 비용 0). 2,984 아래로 떨어지면 실패 |

"변론기일 … 지정됨"은 사용자 기준("예약됨 = 일정")과 같은 꼴이라 일정으로 두었다.

## 정책 차이 (통과로 셈, 따로 표시)

- **지난 시각 → 내일 (30건)**: 밤 9시에 "15:00까지"라고 쓰면 데이터는 오늘(이미 지남), 앱은 내일로 읽는다. 앱 쪽이 쓸모 있다고 보고 유지.
- **기준 날짜 없는 "하루 미뤄줘" (143건)**: 데이터는 "보류(확인 필요)", 앱은 오늘 기준으로 계산하고 결과 카드 ×로 되돌릴 수 있다.
- **"~하는 날" (10건)**: 마감이 아니라 '할 날'로 넣는다.

## 다른 AI 제안(daynote.md · daynote2.md) 검토

| 제안 | 반영 |
|---|---|
| 상대 날짜 후단 계산 (하루 미뤄 → 앱이 기존 날짜 + 1) | 이미 있음 + 동사 확장 |
| CLEAR(due: null) 환각 방지 | 반영 — 분명한 지우기 말이 근거에 있을 때만, 되돌리기 가능 |
| 실행 전 확인 (Draft vs Apply) | 상태를 바꾸는 명령(완료·삭제·시작·멈춤·되돌리기·배치)에 확인 카드로 반영. 새 할 일 만들기는 지금처럼 바로 + 카드에서 고치기·빼기·Ctrl+Z |
| "관련 메모" 머리말 + 할 일 = task | 반영 — 머리말·맺음말("확인 바람", "이상.")은 기록으로 안 셈 |
| due vs do_at 조사 규칙, 끝 시각 역산 블록 | 프롬프트는 그대로(이미 규칙 있음). 역산 블록은 보류 — 마감만 있는 일은 추천에서 시간을 잡는다 |
| 1,000건 97.5% 수치 | 실제 AI를 부른 결과가 아니라 규칙 검증 수치로 보여 그대로 비교하지 않음 |
