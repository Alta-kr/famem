# 프로젝트 브리프

## 제품
대충 던진 메모를 AI가 투두리스트, 메모, 프로젝트별 히스토리로 자동 정리해 주는 앱
(데스크톱 + 스마트폰 연동)

## 타겟
- 1차: 여러 프로젝트를 혼자 굴리는 1인 실무자 (프리랜서, 1인 창업자, 엔지니어, 연구원)
  - 메모장, 노션, 카톡 '나와의 채팅' 등에 메모를 흩어 두고 정리를 못 하는 사람
- 2차 확장: 공공기관·기업용 설치형 버전 (로컬 AI 서버, 인수인계서 자동 생성)

## 핵심 차별점
- 프로젝트 히스토리 자동 기록
- 주간 리포트 자동 생성

## 제약 조건
- 개발 인력: 1인 (앱 배포 경험 없음, 마크다운 에디터는 직접 개발, AI 적극 활용), 주당 20시간
- 예산: 30만 원
- 출시 목표: 3개월 안에 첫 버전 (1개월 → 3개월로 변경)

## 지금까지 결정된 것
1. **사용자 목표**: 사용자 100명. 첫 유입 채널은 아직 없음
2. **성공 기준**: 1년 안에 유료 사용자가 생기고, 그 사용자가 3개월 이상 계속 쓰면 성공. 실패하면 사업을 접고 개인용으로 사용
3. **입력 경로**: 사용자가 이미 쓰는 메모장, 노션, 나와의 채팅 등. 핵심 문제는 '정리가 안 된다'는 것
4. **해결할 귀찮음** (창업자 본인이 옵시디언을 쓰며 겪은 것)
   - 매일 투두리스트를 업데이트하는 것
   - 메모를 정리하는 것
   - 완료한 투두를 히스토리에 옮기는 것
   - 목표: 나중에 히스토리를 쭉 읽으면 프로젝트가 어떻게 흘러갔는지 알 수 있을 것
5. **산출물의 독자**: 본인, 인수인계받는 후임자, 직장 상급자, 클라이언트, 지도교수
6. **가격**: 첫 달 무료 체험 후 월 구독 7달러 (2~3달러에서 인상)
7. **결제 수단**: 안드로이드 앱스토어 결제, 카카오페이, 토스. 데스크톱 버전은 당분간 무료(결제 없음)
8. **플랫폼**: 데스크톱(Windows) 먼저
9. **제품 형태**: 마크다운 에디터 + AI 기능. 창업자가 직접 만든 마크다운 에디터 코드를 사용 (코드는 추후 전달)
10. **AI**: 1차 버전은 클라우드 AI. AI 호출을 API 계층 뒤로 분리해 나중에 상용·로컬 모델로 바꿀 수 있게 만듦
11. **대기자 명단**: 없음
12. **사업자등록**: 할 예정
