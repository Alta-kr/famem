# 검증에서 찾은 버그 목록 (2026-10-16 ~ 17)

- 아직 검증하지 않은 구간: S2 기록·AI 결과 처리, S3 Google 로그인·캘린더 동기화, S4 데이터 저장·백업·데스크톱 앱, S5 할 일·메모·추천, S6 캘린더 배치, S7 현재 상태·프리셋, S8 학습, S9 슬래시 명령어·도우미, S10 앱 전체 사용자 흐름

- 마지막 재점검 에이전트는 세션 한도로 돌지 못해, 대신 직접 확인했다: 두 시간대 테스트 839/839, 바뀐 JS 파일 `node --check`, Electron smoke(화면 18개·가짜 AI 정리·저장·콘솔 오류 0), 폰 390px·PC 1440px 화면 8개(콘솔 오류 0)
